# E2E テスト項目

## 購入フロー（オンチェーン検証）

| # | テスト名 |
|---|---|
| 1 | ウォレット接続後にアドレスが表示される |
| 2 | 購入ボタン押下で approve が発生する |
| 3 | approve 承認後に purchase が発生する |
| 4 | 購入完了後に soldCount が 1 増える |
| 5 | 購入完了後に買い手の JPYC が減る |
| 6 | 購入完了後に Marketplace の JPYC が増える |

## 管理者機能（オンチェーン検証）

| # | テスト名 |
|---|---|
| 7 | 販売開始後に isSaleActive がオンチェーンで true になる |
| 8 | 販売停止後に isSaleActive がオンチェーンで false になる |
| 9 | 価格変更後に price がオンチェーンで更新される |
| 10 | 引き出し後に Marketplace の JPYC 残高がオンチェーンで 0 になる |
| 11 | 引き出し後にオーナーの JPYC 残高が増える |

## 異常系（購入）（オンチェーン検証）

| # | テスト名 |
|---|---|
| 12 | ウォレット未接続で購入できない |
| 13 | approve をキャンセルすると購入がキャンセルされる |
| 14 | 購入承認をキャンセルすると購入がキャンセルされる |
| 15 | 販売停止中に購入できない |
| 16 | 残高不足で購入できない |

## 異常系（管理者）（オンチェーン検証）

| # | テスト名 |
|---|---|
| 17 | 販売開始をオーナー以外ができない |
| 18 | 販売停止をオーナー以外ができない |
| 19 | 価格変更をオーナー以外ができない |
| 20 | 売上引き出しをオーナー以外ができない |
| 21 | 販売開始・停止・価格変更・引き出しを MetaMask でキャンセルすると状態が変わらない |
